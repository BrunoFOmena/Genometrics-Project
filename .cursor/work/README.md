# Work logs (agente)

Uma pasta **`/<slug>/`** por funcionalidade em andamento:

- **`LOG.md`** — diário da feature (progresso, testes, pendências).
- **`PR.md`** — rascunho da PR (só após Bruno autorizar; ver `.cursor/rules/git-release-flow.mdc`).

Arquivar **só após** aprovação em **test**, cherry-pick, PR/merge em **prod** e deploy **prod** ok (ver `branch-deploy-flow.mdc`). Mover para **`arquivados/<slug>/`**.

Conteúdo aqui é **local** (gitignored), exceto este README.
