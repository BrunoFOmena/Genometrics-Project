# Docs_Bruno

Pasta para anotações do Bruno (**gitignored**, exceto este README): planos de produto, boas práticas, rascunhos de sessão, checklists — **fora** do código e **fora** de `.cursor/`.

Sugestão de organização (crie subpastas conforme precisar):

- `planos/` — planos de refatoração, roadmap, decisões em aberto  
  - Ex.: `planos/refatoracao_genometrics_analytics.plan.md` (migrado de `~/.cursor/plans/`)
- `boas-praticas/` — convenções pessoais, fluxos de trabalho
- `notas/` — scratch de conversas com agente, ideias

Documentação **oficial do produto** continua em `README.md` e `AGENTS.md` na raiz. Regras **executáveis** do agente ficam só em `.cursor/rules/`.
